# ✅ Task Management Application

## 📌 Project Overview

The **Task Management Application** is a web-based application developed to help users create, manage, and organize their daily tasks efficiently.

The application provides a simple and user-friendly interface where users can register, log in, and manage their tasks through an interactive task management dashboard.

---

## 🎯 Objective

The main objective of this project is to develop a simple and interactive web application that helps users organize their tasks and improve productivity.

The project demonstrates the practical implementation of **HTML, CSS, and JavaScript** in developing a functional web application.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub

---

## 📚 Application Modules

### 🔐 1. Login Module

The Login Module allows registered users to securely access the task management application.

**Features:**
- User login form
- Username/Email input
- Password input
- Form validation
- Login functionality

---

### 📝 2. Register Module

The Register Module allows new users to create an account.

**Features:**
- User registration form
- Username input
- Email input
- Password input
- Confirm password
- Form validation
- Account creation interface

---

### 🏠 3. Index / Task Management Module

The main index page provides the task management interface.

**Features:**
- Add new tasks
- Display tasks
- Update tasks
- Delete tasks
- Mark tasks as completed
- Organize tasks
- Interactive task management

---

### 🎨 4. Style Module

The `style.css` file is responsible for the visual design and layout of the application.

**Features:**
- Responsive layout
- Navigation styling
- Login and registration form styling
- Task card styling
- Buttons and input styling
- Colors, fonts, spacing, and layout
- User-friendly interface

---

### ⚙️ 5. JavaScript Module

The `script.js` file provides the interactive functionality of the application.

**Features:**
- Form validation
- Task creation
- Task deletion
- Task completion
- Dynamic task updates
- User interactions
- DOM manipulation
- Event handling
