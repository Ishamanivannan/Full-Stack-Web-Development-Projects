# 🛒 E-Commerce Web Application

## 📌 Project Overview

A simple and user-friendly **E-Commerce Web Application** developed to demonstrate the basic features of an online shopping platform.

The project includes user authentication pages and a shopping cart interface with a clean and responsive design.

## ✨ Features

- 🔐 User Login
- 📝 User Registration
- 🛍️ Product Display
- 🛒 Shopping Cart
- ➕ Add Products to Cart
- ➖ Manage Cart Items
- 💰 Cart Total
- 📱 Responsive User Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Main Modules

- **Login Page** – Allows registered users to access the application.
- **Register Page** – Provides a form for new users to register.
- **Cart Page** – Allows users to view and manage selected products.

## 🎯 Objective

The objective of this project is to build a simple e-commerce interface and gain practical experience in **web design, user interaction, form handling, and shopping cart functionality**.

## 💡 Skills Demonstrated

- Front-End Web Development
- HTML
- CSS
- JavaScript
- Responsive Design
- Form Handling
- User Interface Design
- DOM Manipulation

## 🚀 Project Outcome

This project demonstrates the development of a basic e-commerce application with essential **login, registration, product, and cart functionalities**.
